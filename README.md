# 🧠 MindCare App  

A simple mental health check-in web app that helps users reflect on their mood and needs, and provides supportive responses.  

---

## 🎯 Purpose  

In daily life, people often ignore or suppress their emotional state due to stress, routines, or responsibilities.  

MindCare App encourages users to pause for a moment, reflect on how they feel, and identify what they need emotionally.  

The goal is not to solve problems, but to increase emotional awareness through small, supportive check-ins.  

---

## ✨ Features  

- Mood selection (happy, neutral, sad, stressed, tired)  
- Need selection (calm, talk, rest, focus, distraction)  
- Data-driven response system based on mood + need combinations  
- Multiple responses per combination (randomized output for more natural experience)  
- History tracking for previous check-ins  
- Smooth UI interactions and simple animations  
- Active state highlighting for better user experience  

---

## 🛠 Tech Stack  

- HTML  
- CSS (custom styling + animations)  
- JavaScript (state management & data-driven logic)  

---

## 🧠 How It Works  

The app is built around a simple state-driven logic:  

- User selects a mood and a need  
- Selections are stored in a state object  
- The system finds the matching response group  
- A random response is selected from multiple available options  
- The result is displayed dynamically in the UI  
- Each interaction can be stored in history for later review  

This approach keeps the logic scalable, flexible, and easy to extend without complex conditional structures.
